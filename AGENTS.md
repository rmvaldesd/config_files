# AGENTS.md

## Language: English

Everything must be done and read in English, unless the user says otherwise.

- Produce all artifacts in English: code, identifiers, comments, commit messages,
  documentation, prompts and user-facing strings.
- Work through and reason about the repository in English, even when existing files are
  written in another language. Legacy files in Spanish are not a reason to write new work
  in Spanish.
- Communicate with the user in English.
- A request in another language is not an override by itself. The rule is overridden only
  when the user explicitly asks for another language, and only for that request.
